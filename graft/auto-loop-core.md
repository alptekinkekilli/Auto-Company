## Summary

The central orchestration script (scripts/core/auto-loop.sh) and its extracted decision functions: cycle counter, budget gates, idle skip, escalation, engine selection, cycle metadata extraction, and spend accounting. It is the subject of the largest share of the test suite, which extracts functions verbatim via awk to drive the shipping code rather than copies. Key invariants: monotonic cycle counter across redeploys, fail-closed budget/ccusage handling, off-hours ticks never burn cycle numbers, and per-cycle engine attribution overriding any global harness value.
