## Summary

A cross-cutting invariant across the codebase: any check that cannot complete is a REFUSE/NA, never an ALLOW/0. This appears in send-gate (unresolvable checks refuse), ccusage fail-closed reads (degraded reads latch a hold and return NA, never lower a prior observation), work-window (corrupt state fails open with exit 10), site-contact-evidence (a fetch returning no rendered content is inconclusive, never negative), and the model-hint rule (a hint must never override an actual completed model). The philosophy is that a typo or outage must never cause a harmful action or a false 'all clear'.
