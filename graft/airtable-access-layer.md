## Summary

Scoped, auditable Airtable access outside the MCP cycle. airtable-read prevents cycles from pulling whole tables (28,717 bytes/$2.41 per call) by refusing unscoped reads and naming the fixing flag; it switches to POST /listRecords past a 15,000-char URL threshold and clips cells with a marker. airtable-write reads the target row first, applies only specified fields via PATCH, reads back and verifies, with guards for dry-run default, clearing non-empty fields, and replacing >300-char strings. Both load secrets from runtime.env or macOS Keychain, never argv.
